About this search engine

A full-text search engine built entirely from scratch over {{ stats.doc_count }} Philippine Supreme Court decisions promulgated between 2010 and 2026.

No Elasticsearch, no Lucene, no Postgres full-text search, no vector database, and no embedding API anywhere in the retrieval path. Every component - crawler, parser, tokenizer, inverted index, and ranking function - is hand-written in Python.

How it works

  1. Crawl decisions from the LawPhil Project Polite, resumable crawler fetches the full text of every decision from 2010 onward.
  2. Parse and normalize each decision Extracts case title, G.R. number, date, ponente, division, and body text from raw HTML.
  3. Tokenize with a domain-aware tokenizer Handles legal citations (G.R. No. 192393), section references, and Latin terms (res judicata, habeas corpus) as single tokens.
  4. Build a positional inverted index Records every position of every term in every document. Postings are compressed with delta encoding and variable-byte (varint) coding.
  5. Rank with BM25 Tuned at k1=1.2, b=0.75 via parameter sweep over 29 judged queries. Achieves P@10 = 0.879 and MRR = 0.983.
  6. Return highlighted snippets Snippets are anchored at the first matching position in the document and highlighted using the same stemmer as the index.

Search syntax

All terms are required by default (AND logic). Use the operators below to refine your search.

All terms grave abuse of discretion
Exact phrase "beyond reasonable doubt"
Either term mandamus OR certiorari
Case citation G.R. No. 192393 or gr:192393
By ponente ponente:Leonen
By year year:2019
By division division:"En Banc"
Combined ponente:Caguioa year:2019 certiorari
